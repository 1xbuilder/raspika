# Raspika bot — деплой на bothost.ru (Нидерланды)

⚠️ ЭТО ОТДЕЛЬНЫЙ бот, НЕ замена твоему homework-боту (у того свои функции ДЗ/групп).
Заливай его как НОВЫЙ репозиторий/бот, старый homework-бот не перезаписывай.

⚠️ БЕЗОПАСНОСТЬ: если репозиторий на GitHub публичный — НЕ коммить токен.
Файла `.env` тут нет специально (в `.gitignore`). `BOT_TOKEN` задавай в панели
«Переменные» на bothost, а не в коде.

Бот уведомлений Raspika. Ловит нажатие «Уведомлять об изменениях» с сайта raspika.com,
оформляет подписку через ядро и умеет отписку. Лёгкий: только `httpx`, без aiogram.

## Зачем отдельный хостинг
Наш основной сервер в России, и Telegram long-polling (getUpdates) там душится.
bothost.ru (Нидерланды) до Telegram достаёт нормально — поэтому бот живёт здесь,
а ядро (raspika.com) остаётся на нашем сервере. Бот ходит к ядру по HTTPS.

## Файлы
- `raspika_bot.py` — сам бот (точка входа).
- `requirements.txt` — зависимости (`httpx`).
- `.env.example` — переменные.

## Переменные (задать в панели bothost или в .env)
- `BOT_TOKEN` — токен @raspiskaOFF_bot из @BotFather. Возьми СВЕЖИЙ (сделай `/revoke` —
  прежний засвечен). В чат больше не присылай.
- `CORE_URL` — `https://raspika.com` (не менять).

## Запуск на bothost.ru
1. Создай бот-инстанс, залей файлы (или только `raspika_bot.py`).
2. Точка входа / команда запуска: `python raspika_bot.py`
3. Зависимости: `pip install -r requirements.txt` (нужен только `httpx`).
4. В «Переменных» задай `BOT_TOKEN` и `CORE_URL=https://raspika.com`.
5. Запусти. В логах должно появиться: `raspika_bot запущен (long-polling)`.

## Проверка
- Открой raspika.com → выбери группу → «Уведомлять об изменениях» → откроется бот → Start.
- Бот ответит: «🔔 Готово! Буду присылать сюда изменения расписания группы …».

## Важно
- Один токен = один потребитель getUpdates. Наш серверный бот отключён —
  не запускай второй экземпляр этого бота на том же токене (будет конфликт 409).
- Рассылка изменений идёт с нашего сервера (notifier по таймеру), отправка — короткие
  запросы sendMessage, они с РФ проходят. Если вдруг доставка станет нестабильной —
  перенесём и отправку на bothost.
